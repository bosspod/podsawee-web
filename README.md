# podsawee.com Next.js rebuild

Next.js App Router, TypeScript, Tailwind CSS, server-rendered multilingual content, and an interactive GPA/GPAX calculator.

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

Public routes: `/`, `/grade`, `/en`, `/en/grade`, `/zh-CN`, and `/zh-CN/grade`. See `docs/SEO_MIGRATION.md` for the legacy audit, parity comparison, source limitations, and release checklist.
